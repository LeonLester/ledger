# Design
World: chalked programming sheet in a plate-loaded gym. Graphite and chalk, plate colours as the only semantic colour.
Colour (dark / light): a five-step tonal ladder, page #0b0d10 / #e8ebef, field #0f1216 / #f4f6f8, panel #151920 / #ffffff, control #1d222a / #eef1f4, hover #29303a / #dfe4ea. Two line weights: hairline #353d49 / #c5ccd6 between rows and around panels, outline #566070 / #8d97a5 around every control and input. Text #eceae4 / #13161a, accent plate blue #2f6bff / #1f56e0. Semantic: red #ef5a4d near failure or over MRV, yellow #f2c230 approaching, green #3fbf78 on target.
Type: Roboto (variable) for headings, lift names and UI, tabular numerals for all load data.
Components: segmented control, sheet, disc (set done), track bar (volume), plate stack, rest bar.
Rules: flat panels with 1px hairlines, 8px panel and 6px control radius, no shadows; controls and fields always carry the outline weight; the active segment is inverted (chalk fill); muscle colour is a 9px swatch beside the name, never a side bar; a superset is one 1px accent frame around its members; no cards inside cards, no eyebrow labels, one motion moment (sheet rise), reduced motion respected.
