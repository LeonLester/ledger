# Design
World: chalked programming sheet in a plate-loaded gym. Graphite and chalk, plate colours as the only semantic colour.
Colour (dark / light): bg #101215 / #f2f0e9, surface #171a1f / #ffffff, text #ecebe5 / #15171a, accent plate blue #2f6bff / #1f56e0. Semantic: red #ef5a4d near failure or over MRV, yellow #f2c230 approaching, green #3fbf78 on target.
Type: Big Shoulders Display 800 for headings and lift names, Hanken Grotesk for UI, tabular numerals for all load data.
Components: segmented control, sheet, disc (set done), track bar (volume), plate stack, rest bar.
Rules: no cards inside cards, no eyebrow labels, one motion moment (sheet rise), reduced motion respected.
